# 留白日記

> 把心裡的聲音，安靜地留在自己的裝置裡。

**留白日記**是一款離線、無帳號、以內容為主的原生 Android 日記 App。沒有動態牆、沒有複雜分類，也不要求每天完成任務；打開 App，就能直接寫下今天。

日記以裝置私有資料儲存，App 不需要網路才能使用，也不會主動把內容上傳到伺服器。你可以專心書寫，需要時再自行匯出備份或 PDF。

## 為什麼做這個 App

許多日記 App 放進了社群、訂閱、雲端帳號與大量提醒，真正用來寫字的空間反而越來越少。

留白日記選擇保留最必要的功能：快速寫下內容、找回過去的記錄、看見自己的累積，並把資料掌握在自己手上。

## 功能亮點

### 專心寫下今天

- 新增、閱讀、編輯與刪除日記
- 設定日期與當天心情
- 輸入時自動儲存
- 閱讀時顯示字數，編輯時即時更新
- 既有日記預設以只讀模式開啟，避免誤觸修改
- 淺色與深色模式跟隨 Android 系統

### 找回過去的記憶

- 搜尋標題、內文或心情
- 從搜尋結果閱讀日記後，保留原本的關鍵字、結果與列表位置
- 使用月曆查看每天是否寫過日記
- 從月曆直接開啟指定日期的內容

### 看見書寫的累積

- 累積字數與日記總數
- 寫過日記的天數
- 平均每篇字數
- 最長一篇與本月統計
- 點擊「最長一篇」即可直接閱讀，返回後仍停留在統計頁

### 自己保管、自由帶走

- 匯出 JSON 備份，並可與現有日記合併匯入
- 匯出排版完成的 A4 PDF
- PDF 支援單篇、全部、本月與自訂日期範圍
- 所有核心功能皆可離線使用

## 隱私與資料安全

日記內容儲存在 App 的裝置私有目錄。App 本身不需要帳號，也不需要網路權限才能完成書寫、搜尋、統計與匯出。

> 匯出的 PDF 與 JSON 備份是可直接閱讀的明文檔案，可能含有私人內容，請只儲存在你信任的位置。PDF 適合閱讀與列印；JSON 才能用來還原 App 資料。

更新 APK 前，建議先從 App 匯出一份 JSON 備份。請使用相同 package 與簽章直接覆蓋安裝，不要解除安裝，也不要選擇「清除儲存空間／清除資料」。

## 建置

建置環境需要 OpenJDK 21、Android SDK platform 37 與 build-tools 36.0.0。

```sh
./android/build.sh
```

輸出：

```text
dist/liubai-journal-1.9-debug.apk
```

## 安裝

連接 Android 裝置或啟動模擬器後執行：

```sh
/opt/homebrew/share/android-commandlinetools/platform-tools/adb install -r dist/liubai-journal-1.9-debug.apk
```

`-r` 代表覆蓋更新既有 App，正常情況下會保留原本的裝置私有資料。若 Android 顯示簽章不符，請先停止安裝並保留錯誤訊息，不要直接解除安裝。

此 APK 使用 Android debug key 簽章，適合個人安裝與測試，不是 Google Play 正式上架版。
