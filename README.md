# 留白日記 Android

一個離線、無帳號、以內容為主的極簡日記 App。

## 功能

- 新增、編輯與刪除日記
- 開啟既有日記時預設為只讀模式，雙擊內容或按「編輯」即可修改
- 閱讀日記時顯示字數，編輯時隨輸入即時更新（標題與內文，不計空格與換行）
- 月曆檢視：切換月份、查看哪些日期有日記，並直接開啟當天內容
- 設定日期與心情
- 搜尋標題、內容或心情
- 底部導覽：在「日記」、「統計」與「設定」之間切換
- 書寫統計：累積字數、書寫日數、平均字數、最長篇幅與本月統計；可從「最長一篇」直接開啟日記
- 匯出排版完成的 A4 PDF：支援單篇、全部、本月與自訂日期範圍
- 匯出 JSON 備份，並從備份檔合併匯入日記
- 輸入時自動儲存
- 淺色／深色主題跟隨系統
- 全部資料只儲存在 App 的裝置私有目錄

> 匯出的 PDF 與 JSON 備份都是可直接閱讀的明文檔案，可能含有私人日記內容，請儲存在信任的位置。PDF 適合閱讀與列印；JSON 才能用來還原 App 資料。

## 建置

```sh
./android/build.sh
```

輸出：`dist/liubai-journal-1.8-debug.apk`

## 安裝

```sh
/opt/homebrew/share/android-commandlinetools/platform-tools/adb install -r dist/liubai-journal-1.8-debug.apk
```

此 APK 使用 Android debug key 簽章，適合個人安裝與測試，不是 Google Play 正式上架版。
